# Sprint 1 Retrospective

## Çfarë shkoi mirë

* Komunikimi në ekip ishte i mirë.
* GitHub Issues dhe Projects ndihmuan në organizimin e punës.
* Dokumentacioni u përgatit në kohë.
* Shumica e detyrave u përfunduan sipas planit.

## Çfarë nuk shkoi mirë
* Disa detyra morën më shumë kohë sesa ishte planifikuar.

## Çfarë do të ndryshojmë në sprintin e ardhshëm

1. Të bëjmë commit më të shpeshta.
2. Të përdorim branch të veçanta për çdo funksionalitet.
3. Të kryejmë code review para çdo merge.
4. Të mbajmë komunikim ditor për progresin.
5. Të planifikojmë më mirë kohën për testim.

## Veprime për Sprint 2

* Përfundimi i funksionaliteteve të mbetura.
* Përditësimi i dokumentacionit pas çdo ndryshimi.
